# Java OOP Pillars Assignment

A beginner-friendly Java assignment demonstrating the four pillars of Object-Oriented Programming.

## Four Pillars

### 1. Encapsulation
- StudentEncapsulation
- BankEncapsulation
- EmployeeEncapsulation
- ProductEncapsulation

### 2. Inheritance
- AnimalInheritance
- VehicleInheritance
- EmployeeInheritance
- ShapeInheritance

### 3. Polymorphism
- MethodOverloading
- ConstructorOverloading
- MethodOverriding
- RuntimePolymorphism

### 4. Abstraction
- BankAbstraction
- VehicleAbstraction
- ShapeAbstraction
- EmployeeAbstraction

## Technologies
- Java
- NetBeans IDE
- Git
- GitHub

## Package
All programs use:

```java
package oop.pillars.program;
```

## How to Run

1. Open NetBeans.
2. Choose **File > Open Project**.
3. Select the `Java-OOP-Pillars` folder.
4. Expand `Source Packages > oop.pillars.program`.
5. Right-click any Java class.
6. Select **Run File**.

Each program has its own `main()` method.
